# Power Forge Documentation

Documentation for Power Forge, an offline-first character creation and battle simulation app.

## Version 20

This folder contains release notes, customization documentation, project requirements, build instructions, and screen design references.

## Part Workshop

Documentation for modular character parts, appearance customization, drawing tools, reusable custom parts, and character previews.

## Release Validation

Automated tests and Android release-build checks must pass before the project is considered ready for device testing.

## Artwork

Character illustrations and power effects are stored in the assets directory.

## Status

Android device testing will be performed separately after the code and build checks are complete.
